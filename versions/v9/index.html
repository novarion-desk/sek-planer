Cloud-Sync Diagnose (Zürich), KI-Keys & Backup

Firebase Cloud-Status & Wiederherstellung Prüfe...
Funktioniert die erste KI nicht (überlastet, kein Guthaben), springen automatisch die anderen hinterlegten KIs ein. Sprachmemos transkribiert immer Gemini.
ℹ️ Anleitung: So fügst du deinen KI-Schlüssel ein (klicken)
1. Öffne aistudio.google.com/apikey und melde dich mit deinem Google-Konto an.
2. Klicke auf «API-Schlüssel erstellen» (Create API key) und kopiere den Schlüssel (beginnt mit AIza…).
3. Füge ihn oben ins Feld «Google Gemini API-Key» ein und klicke auf «KI testen».
4. Erscheint ✅, klicke unten auf «Einstellungen speichern».
Optional: Claude-Schlüssel als zweite KI
1. Öffne platform.claude.com (Claude Console) und melde dich an. Das ist ein separates Konto neben dem Claude-Abo – die API wird über vorausbezahltes Guthaben abgerechnet.
2. Unter Billing Guthaben aufladen, dann unter API Keys → «Create Key» und den Schlüssel kopieren (beginnt mit sk-ant-…).
3. Ins Feld «Claude API-Key» einfügen, oben wählen, welche KI zuerst verwendet wird, dann «KI testen» und «Einstellungen speichern».
Optional: ChatGPT-Schlüssel
1. Öffne platform.openai.com und melde dich an. Auch hier gilt: Das ChatGPT-Abo enthält keine API – sie wird separat über Guthaben abgerechnet.
2. Unter Billing Guthaben aufladen, dann unter API keys → «Create new secret key» und den Schlüssel kopieren (beginnt mit sk-…).
3. Ins Feld «ChatGPT (OpenAI) API-Key» einfügen, dann «KI testen» und «Einstellungen speichern».
Die Schlüssel gehören zu deinem Konto: Sie sind nach dem Anmelden auf all deinen Geräten verfügbar, andere Konten sehen sie nicht.
