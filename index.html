Schlüssel von Gemini, Claude, ChatGPT oder Mistral einfügen – der Anbieter wird erkannt und der Schlüssel vor dem Speichern getestet.
Reihenfolge mit ↑↓: Die oberste KI wird zuerst gefragt. Ist sie überlastet oder ohne Guthaben, springt automatisch die nächste ein. Sprachmemos: Gemini, ChatGPT oder Mistral in dieser Reihenfolge (Claude kann keine Tonaufnahmen). Schlüssel und Reihenfolge gelten auch im Zeitstrahl.
ℹ️ Anleitung: So bekommst du einen KI-Schlüssel (klicken)
Gemini (empfohlen, mit Gratis-Kontingent)
1. Öffne aistudio.google.com/apikey und melde dich mit deinem Google-Konto an.
2. Klicke auf «API-Schlüssel erstellen» (Create API key) und kopiere den Schlüssel (beginnt mit AQ., ältere mit AIza).
3. Oben einfügen und «Prüfen & hinzufügen» klicken – fertig, er wird sofort gespeichert.
Claude
platform.claude.com (Claude Console) – separates Konto neben dem Claude-Abo, abgerechnet über Guthaben. Unter API Keys → «Create Key» (beginnt mit sk-ant-). Mit einem Max-Abo gibt es monatliches API-Guthaben (Einstellungen → Abrechnung → «Link organization»).
ChatGPT
platform.openai.com – das ChatGPT-Abo enthält keine API. Guthaben aufladen, dann API keys → «Create new secret key» (beginnt mit sk-).
Mistral
console.mistral.ai → API Keys → «Create new key».
Die Schlüssel gehören zu deinem Konto: Sie sind nach dem Anmelden auf all deinen Geräten verfügbar, andere Konten sehen sie nicht.
